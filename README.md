# Product Ratings and Review Analytics Dashboard

A full-stack web application for analyzing product ratings, reviews, and performance metrics.

## Features

- Interactive dashboard with charts and graphs
- CSV/Excel file upload for product and review data
- 🔍 Advanced search and filtering capabilities
- Real-time analytics (products per category, top reviewed products, discount distribution)
- Modern UI with Material-UI
- Redux Toolkit for state management

## Tech Stack

### Backend
- Node.js & Express.js
- PostgreSQL database
- RESTful API architecture
- Multer for file uploads
- XLSX for Excel processing

### Frontend
- React 18
- Material-UI (MUI) for styling
- Redux Toolkit for state management
- Recharts for data visualization
- Axios for API calls


## Installation

### Prerequisites
- Node.js (v18 or higher)
- PostgreSQL (v14 or higher)
